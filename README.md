# ResumePilot

ResumePilot is an AI-powered resume analysis application that compares a user's resume against a job description and provides a structured assessment of how well the resume matches the position.

## What It Does

ResumePilot allows users to:

- Upload a PDF resume
- Paste a job description directly
- Provide a company career-page URL
- Extract and process job posting content
- Analyze the resume against the job description using an LLM
- Receive a match score, strengths, skill gaps, relevant experience, and recommendations
